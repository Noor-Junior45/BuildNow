## 2026-09-21 - Found Hardcoded Supabase Anon Key in src/lib/supabaseClient.ts\n**Vulnerability:** Found hardcoded `VITE_SUPABASE_ANON_KEY` and `VITE_SUPABASE_URL` strings in `src/lib/supabaseClient.ts` acting as fallbacks, which can be scraped or leaked.\n**Learning:** API keys and Secrets should NEVER be hardcoded into source code, even as fallbacks. Environmental variables should always be the source of truth.\n**Prevention:** Utilize `import.meta.env` exclusively for fetching environment variables and throw an error or handle gracefully if not present.
